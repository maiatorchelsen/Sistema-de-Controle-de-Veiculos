# Projeto Engenharia de Software 2

Este projeto foi desenvolvido para a disciplina de Engenharia de Software 2, 3º semestre do curso de Análise e Desenvolvimento de Sistemas.

## Estrutura do Projeto

- **index.ts**: Arquivo principal do projeto.
- **Veiculo.ts**: Contém a definição da classe ou funções relacionadas a veículos.
- **package.json**: Gerencia as dependências e scripts do projeto.
- **tsconfig.json**: Configuração do TypeScript.
- **requisitos.MD**: Documento com os requisitos do projeto.

## Como executar

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Compile o projeto TypeScript:
   ```bash
   npx tsc
   ```
3. Execute o arquivo principal:
   ```bash
   node index.js
   ```

## Requisitos
Consulte o arquivo `requisitos.MD` para mais detalhes sobre as funcionalidades e requisitos do projeto.
